# ADR 001 — Local-first Next.js

Date: 2026-11-14

The repository contained only the MIT license. Fujara is a Next.js 15 + TypeScript app with Tailwind 4, stored in this folder.

IndexedDB holds audio and metadata so the player runs with no paid services. Postgres and Google Drive are documented extensions, not requirements for playback.

Rejected for this milestone: a monorepo, Redis, a transcoding service, and native store apps.
